# La Rústica ERP — starter mobile-first

Primer scaffold Next.js para el panel mobile-first, con identidad visual La Rústica (Bone/Sand/Charcoal/Copper), panel de inicio, navegación inferior y conexión cliente Supabase preparada.

## Ejecutar localmente

1. Instalar Node.js LTS.
2. `npm install`
3. Copiar `.env.example` a `.env.local` y completar URL y publishable key del proyecto Supabase.
4. `npm run dev`
5. Abrir `http://localhost:3000`

Este scaffold es una interfaz inicial con datos de placeholder; aún no está desplegada ni conectada a consultas de dashboard. Nunca colocar claves service-role en frontend.
